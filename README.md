## 🎮 Sobre o projeto

O computador sorteia um número secreto e você tenta adivinhar qual é.
A cada palpite, o jogo diz se o número é **maior** ou **menor** que o seu chute,
até você acertar. Ao final, mostra em quantas tentativas você conseguiu!

## ✨ Funcionalidades

- 🎲 Sorteio aleatório de um número secreto a cada partida
- 💡 Dicas após cada palpite (o número é maior ou menor)
- 🔢 Contador de tentativas
- 🔄 Botão para reiniciar e jogar novamente
- 📱 Interface simples e responsiva
